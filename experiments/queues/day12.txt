# Day 12: two robustness checks on the 22M model, 3 seeds each.
# (1) Domain order: the key comparison with the stream REVERSED
#     (math -> code -> stories instead of stories -> code -> math).
# (2) LR re-warming (Ibrahim et al. 2024): restart warm-up + cosine at every
#     new domain (true boundaries) — the standard continual-pretraining recipe
#     — with no replay, 1% and 5% replay. Compare with toy_A / toy_A_r01 /
#     toy_A_r05 (single schedule).
# ~4.3 min per run, 21 runs (~90 min). Seed-major: seed 0 of everything first.

# --- seed 0 ---
ord_A        configs/toy_A.yaml       0  --set domains=[math,code,stories]
ord_D        configs/toy_D.yaml       0  --set confirm_steps=3 --set domains=[math,code,stories]
ord_A_r05    configs/toy_A.yaml       0  --set replay_frac=0.05 --set domains=[math,code,stories]
ord_D_seen   configs/toy_D_fall.yaml  0  --set freeze=all_seen_emb --set confirm_steps=3 --set domains=[math,code,stories]
rw_A         configs/toy_A.yaml       0  --set lr_rewarm=true
rw_A_r01     configs/toy_A.yaml       0  --set lr_rewarm=true --set replay_frac=0.01
rw_A_r05     configs/toy_A.yaml       0  --set lr_rewarm=true --set replay_frac=0.05
